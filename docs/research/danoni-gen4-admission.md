# Gen4 native corpus admission

Implemented 2026-10-12. This batch adds the remaining **13 listed gen4 works /
16 five-key charts, 7,998 taps and 365 holds**, with 65 parsed speed events.
The [earlier paired-source admission](danoni-paired-ports.md) already covered
Saigetsu and the listed レク chart of Earthquake Super Shock. All 15 listed
gen4 works now have native exports; ESS's other 54 selections remain outside
that earlier entry's scope. Sources, music, artwork and dumps stay local.

## External charts and native menus

The static survey classified these movies as embedded-data works because its
identifier scan found no literal `dos.txt`. Actual native runs request that
file: `DOS_FILE_NAME = "dos"` supplies a computed filename. All 13 requests
were observed first, then fetched once through the robots-aware, paced cache.
Original acquisition manifests remain byte-identical; supplemental HTTP, robots,
retrieval-date and body-hash receipts are under the new study's acquisition
folder and each work's `inputs/provenance-complete.json`.

The rendered LunaticBlue, Moon and Ura Lover titles show source version 4.01
and base f3d 1.0.2. Those are observed representatives, not an inferred version
for every movie. Each work independently matches the existing `parafla-counter`
contract: played heads equal native spawn plus `judgeY`, raw tails survive,
`frameNum` provides the clock, and `arrowSpd` contains parsed pixel increments.
Its first `[0, setSpd]` pair initializes movement; later pairs become author
multipliers. No new engine adapter, movie allowlist or fitting parameters are
needed. Parsed boosts are empty in this batch.

The recorded menu recipe clicks the title at iteration 200 and Play at 350.
These positions and iterations belong to the input recipe, not the projection
algorithm. All references are prepared at iteration 355, before consumption;
all music streams start at iteration 561 / native frame **202**. Native seconds
remain `(frame - 202) / 60`, independently verified per selector. The existing
narrow missing-attachment review retains only the known post-conversion
undefined-character diagnostics and requires all five played receptors.

[まんまるお月様](http://autumnleaves.yukishigure.com/DOWF_1/M/moon.html) has four
author charts: レク, ★ぞろり★, やんちぃ and めた. Its difficulty-label card advances
the selector through ordinary clicks; all four are captured independently.
`★ぞろり★` is an author name, not a two-star rating.

## Movement, gauges and audio

Base increments range from 2 to 5 source pixels per frame. Movement and source
geometry are proved independently for every chart, with the unchanged
1.5-frame arrival tolerance. All final observed arrivals differ by one native
frame; the tool records that rendering phase rather than shifting note times.

Moon's ★ぞろり★ chart changes speed at native frames 233, 238, 243 and 248.
Its first arrow begins at the earlier slow rate, so extending that flight line
through the impending change incorrectly predicts its arrival. The admitted
measurement uses three stable samples at native frames 234–236, after the
first change: 7.5 px/frame, independently equal to baseline 2.5 times author
multiplier 3. The event takes effect in the drawn position one frame after its
clock entry; transition samples are excluded from a linear measurement.

An unplayed default-gauge run reaches its result screen and freezes `frameNum`
at 244. This is an ordinary in-game failure, not a VM halt. It prevented both
a later-arrow probe and enough clean audio windows. A separate run selects the
published **BarDrain: Practice** option through the menu. Its lanes, holds,
compiled schedules, keys, metadata and pixel-speed units are verified identical
to the default run. The original default capture supplies movement evidence;
the Practice capture supplies longer audio evidence. Both remain intact.
No VM variables, work scripts or resource responses are altered.

Independent native-PCM versus MP3 comparisons pass for all 13 recordings, with
minimum accepted correlation 0.98648 and zero measured decoder-origin lag.
Lapis uses **22.05 kHz stereo**; Sacrifice and Merosupi use **44.1 kHz mono**;
the others use 44.1 kHz stereo. Canonical WAV and final Ogg retain those native
sample rates and channel counts. The resampled stereo comparison is separate
from canonical music. Original Flash/device latency remains unmeasured.

Default musical fitting, independent phases on shared recordings, pickup
previews, Ogg quality and native inverse `#SCROLLS` use the existing generic
policies. Source frames remain exact and exported note endpoints retain the
9 ms bound. Custom engine presentation keeps its documented limitations.

The recipe and reference schemas are unchanged. Per-chart native key codes,
selected field suffixes, parsed pixel speeds, full sparse schedules and reviewed
diagnostics remain in the existing reference fields. Failed probes and the

```sh

  --cache-dir /private/tmp/ddi-ruffle/uv-cache \
  --with-requirements tools/danoni-dump/ruffle/requirements-analysis.txt \
  python tools/danoni-dump/ruffle/extract_native.py \
  "$HOME/Music/DanOni/native-adapters-v6/reku-090-dowf-1-m-moon/recipe-final.json" \
  /private/tmp/moon-export-new
```

Worker reruns use the restricted native wrapper and fresh output directories;
exact cached GET bodies are supplied by the saved configuration. The Ruffle
revision and parent CPU/wall/memory limits are unchanged. See
[native contracts](danoni-native-adapters.md),
[the original ParaFla proof](danoni-paired-ports.md) and
[export rebuilding](danoni-exports.md) for full interfaces and commands.
